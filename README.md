## 演示数据

统一在 [assets/mock.js](./assets/mock.js)：西安邮电大学、林晓、AI 三态、失物/帖子/活动/闲置/会话、待整理队列、3 所学校实例等。

## 建议走查顺序

1. 用户端登录西安邮电大学 → 问「图书馆几点关门」
2. 问课程作业体验 → 草稿发帖
3. 学校管理整理求助 → 对照用户端「管理员已整理」（帖 p3）
4. 问「想收四六级耳机」→ 闲置 → 私信
5. **数字商品买家闭环**：闲置页切「数字商品」/ 我的「数字商品商店」/ 左侧故事线「9. 数字商品买家」→ 详情 → 确认订单 → 支付成功 → 已购内容（在线查看水印 / 短时下载 / 退款 / 投诉）
6. 平台控制台查看/开通学校实例

## 说明

- 无真实登录 / 支付 / AI 接口
- 用户端模拟微信小程序导航与 TabBar
- 管理端为高信息密度中后台工具风


## 功能覆盖（对照 PRD）

- 登录/校区选择、可信度、设置隐私
- AI 对话首页（有来源/无答案相关帖/路由闲置·出售·数字·活动·失物）
- 广场 + 顶部失物、发帖评论点赞收藏举报
- 闲置双频道与数字商品、认证卖家、支付交付结算
- 活动报名收藏、组织身份、推广账户
- 搜索、私信请求/屏蔽举报、通知
- 学校管理：求助整理、候选知识、举报、数字商品/卖家/活动审核、校区共享
- 平台控制台：实例列表/开通/版本运行

模拟数据见 `assets/mock.js`。
